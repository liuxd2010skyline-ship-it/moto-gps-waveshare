# 北京海淀区圆屏底图数据核查

核查日期：2026-10-01。首个实地测试区域为北京市海淀区。目标是在 iPhone 上取得可授权使用的局部道路、建筑、绿地与水体几何，经现有 BLE `MapScene` 发送给微雪 1.75C 圆屏，由现有 LVGL 绘图代码渲染。项目不运行常驻网关，只使用中国数据提供方，要求个人长期免费使用。

## 当前结论

**目前没有一个已证实同时满足细粒度几何、个人长期免费、外接圆屏重绘与允许临时缓存的正式接口。** 因此不把地图瓦片、截图或 SDK 内部数据解析成地物，也不把内置济南演示数据用于海淀真实导航。路线与转向仍可走已测试的百度 iOS 路线链，圆屏底图数据保持待接入状态。此结论仅限已核查的公开文档，不能推断任何提供方一定拒绝授权。

## 使用范围咨询稿（供账号持有人发送；尚未发送）

### 百度地图开放平台

> 我开发一套仅供本人使用、非商业的摩托车便携导航原型。iPhone App 使用本人申请的百度 iOS AK 搜索地点并规划驾车避高速参考路线、自行车及电动自行车路线。手机通过 BLE 把已开放接口取得的路线线条、转向、距离和预计时间发送到车把上的独立 466×466 圆形显示屏；圆屏自行绘制路线和指令，不运行百度 SDK，也不提取百度底图或瓦片。请确认：（1）此个人车把显示屏是否属于服务条款 2.3 的车载场景，是否必须另行签署书面协议，个人免费使用是否可申请；（2）将上述开放的路线和导航提示显示在外接屏上的许可范围、署名及审图要求；（3）若要在该屏上自绘道路、建筑、绿地和水体，贵平台是否有允许取得并临时缓存其几何的正式接口；（4）iOS 导航 SDK 的多实例/后台投屏能力是否适用于该硬件形态及锁屏后运行。

### 天地图·北京

> 我开发一套仅供本人使用、非商业的 iPhone + 车把圆屏导航原型，首个测试区域为北京市海淀区。iPhone 希望通过贵平台正式接口读取当前位置附近数百米内的道路中心线、建筑轮廓、绿地和水域边界，按视野裁剪后经 BLE 发给独立 ESP32 圆屏，由设备使用自定义样式实时绘制。无需常驻服务器，不公开再分发原始数据。请提供：（1）覆盖海淀区且达到街道/建筑级精度的正式要素服务名称、文档与样本；（2）个人开发者免费额度和长期使用条件；（3）是否允许该外接圆屏自绘、短时本机缓存和必要的几何简化；（4）坐标系、更新周期、署名、审图号和其他显示要求。若仅开放预渲染瓦片，也请明确是否允许在此场景中解析瓦片并重绘。

账号持有人发送前可删去不适用的路线模式，但必须保留“车把独立显示屏、自绘、BLE、非商业、短时缓存”这些实际用途。不要附上 AK 明文、设备备份或具体居住地址。

## 落地门槛

1. 获得海淀区正式接口样本，核对缩放级别下道路和地物完整性、坐标系、字段、更新时效及请求容量。
2. 获得明确允许外接圆屏再绘制和必要缓存的使用依据；百度路线链的外接屏用途也需单独确认。
3. 通过后才选择地图源并写 iPhone 适配层；以现有 `MapScene 0x14` 先发送道路和建筑轮廓，绿地/水体根据真实样本扩展协议。未通过时仅显示路线、方向和“无底图”状态。
